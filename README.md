## 👋 Introduction

Welcome to the repository for my personal portfolio website! This project was built to highlight my projects, technical stack, and professional experience through a highly interactive and visually engaging interface.

**Check out the live version here:** [https://sunnik-chatterjee-portfolio-iqx8.vercel.app/](https://sunnik-chatterjee-portfolio-iqx8.vercel.app/)

---

## 🎨 Features

- **Interactive 3D Elements:** Powered by `Three.js` and `React Three Fiber` for immersive user experiences.
- **Smooth Animations:** Cinematic scroll and reveal animations implemented using `GSAP`.
- **Modern UI/UX:** Clean, dark-themed, glassmorphism-inspired design layout.
- **Fully Responsive:** Optimized to look great on desktops, tablets, and mobile devices.
- **Performant:** Built with Vite for rapid development and lightning-fast loading speeds.

## 🚀 Getting Started

If you'd like to explore the code or run this project locally, follow these steps:

### 1. Clone the repository
```bash
git clone https://github.com/Sunnik-Chatterjee/Sunnik-Chatterjee-Portfolio.git
cd Sunnik-Chatterjee-Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the development server
```bash
npm run dev
```

Your app will be running at `http://localhost:5173`.
