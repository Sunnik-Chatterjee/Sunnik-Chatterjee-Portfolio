# Sunnik Chatterjee - Portfolio Website 🚀

Welcome to the repository for my personal portfolio website. It highlights my skills as a Full-Stack & Backend Developer, showcasing my projects, tech stack, and experience.

## ⚙️ Tech Stack

- **Framework**: React, TypeScript, Vite
- **Styling**: CSS, GSAP (Animations)
- **3D Rendering**: Three.js, React Three Fiber, React Three Drei
- **Deployment**: Vercel

## 🚀 Getting Started

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sunnik-Chatterjee/Sunnik-Chatterjee-Portfolio.git
   cd Sunnik-Chatterjee-Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

## 🎨 Features
- Interactive 3D elements powered by Three.js
- Smooth scroll animations using GSAP
- Fully responsive design
- Modern and clean UI
